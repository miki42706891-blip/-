## 計算の前提

- 生活費・教育費・大きな出費は物価上昇率（初期値1％）で毎年増える。住居費と年金は増やさない。
- 預貯金が足りない年は投資を取り崩す。投資の利回りは初期値3％。
- 教育費は文部科学省「子供の学習費調査（令和5年度）」などの平均をもとにした目安（塾・習い事を含む。大学は授業料と入学金のみ）。
